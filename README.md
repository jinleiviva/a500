# A500 温度计 🌡️

中证A500指数估值温度计，每天自动更新。

- **更新频率**：每日 09:30 自动（北京时间）
- **计算公式**：温度 = PE分位 × 60% + 价格分位 × 40%
- **数据源**：价格与实时行情 新浪财经（akshare）；PE 与股息率 中证指数官方（akshare `stock_zh_index_value_csindex`）
- **PE 说明**：PE 取自**中证指数官方静态市盈率（市盈率1）**，为真实估值，经 akshare 每日拉取，自 2026-09-08 起生效。受公开接口限制——中证指数官方仅提供最近约 20 个交易日的估值，乐咕乐股 / 东财等均未覆盖中证 A500 完整历史——故 2026-09-08 之前的历史序列为**按真实 PE 量级校准过的价格派生序列**（形状沿用价格派生、量级对齐官方静态 PE），百分位据此估算。如需严格的历史真实 PE 分位，需接入能回溯 A500 全周期 PE 的付费/专有数据源。

## 颜色含义

| 温度 | 颜色 | 建议 |
|------|------|------|
| 0-30°C | 🟢 低估 | 适合买入 |
| 30-60°C | 🟡 合理 | 继续定投 |
| 60-80°C | 🟠 偏高 | 暂停买入 |
| 80-100°C | 🔴 过热 | 考虑卖出 |
